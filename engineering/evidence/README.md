# Volta Edge V7 — Engineering Evidence

This directory contains machine-verifiable records of project progress.

Evidence must distinguish between:

- PLANNED — intended but not implemented
- IMPLEMENTED — code/configuration exists
- VERIFIED — tested successfully
- HARDWARE-VERIFIED — confirmed on physical hardware

Never record simulated or planned behavior as physical verification.

## Checkpoints

- [CP-000 — ESP-IDF Foundation](checkpoints/CP-000-esp-idf-foundation.md): environment and separate example-build evidence; does not verify VoltaEdge firmware.
- [CP-001 — VoltaEdge Firmware Foundation Build](checkpoints/CP-001-voltaedge-firmware-foundation-build.md): project build and generated-artifact verification only; no flashing, runtime, or hardware verification.
